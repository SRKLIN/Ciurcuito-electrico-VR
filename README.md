## 📌 Descripción del Proyecto

**VR Circuit Lab** es una plataforma de aprendizaje inmersivo desarrollada en **Unity 6** enfocada en el diseño, ensamble y experimentación interactiva con **circuitos electrónicos dentro de un entorno de Realidad Virtual (VR)**. 

El propósito principal de este proyecto es proveer un entorno seguro, accesible e intuitivo donde estudiantes, entusiastas y académicos puedan manipular componentes eléctricos reales (resistencias, fuentes de voltaje, switches, capacitores, LEDs y multímetros) sin los riesgos inherentes del laboratorio físico, tales como:
* 💥 Cortocircuitos y sobrecargas accidentalmente provocadas.
* 💸 Daño térmico o destrucción de componentes costosos.
* ⚡ Riesgos de descargas eléctricas o fallas mecánicas en prototipos.

Mediante interacciones espaciales en 3D y simulaciones de física de componentes, el usuario puede ensamblar esquemas complejos en protoboards virtuales, medir magnitudes eléctricas en tiempo real y validar conceptos teóricos en un laboratorio interactivo de última generación.

---

## 🎯 Objetivos Educativos

Este desarrollo tiene fines **estrictamente académicos e investigativos**, buscando transformar la educación STEM (Ciencia, Tecnología, Ingeniería y Matemáticas) mediante:
1. **Fomento de la Experimentación Segura:** Permitir el "ensayo y error" ilimitado sin costo de material ni peligro físico.
2. **Aprendizaje Visual e Inmersivo:** Facilitar la comprensión de variables invisibles (corriente, voltaje, resistencia) a través de retroalimentación gráfica interactiva y mediciones precisas.
3. **Accesibilidad para Laboratorios Remotos:** Brindar a instituciones educativas la posibilidad de contar con laboratorios completos de electrónica digital y analógica mediante hardware accesible como Meta Quest 2.

---

## 🚀 Características Principales

* 🔌 **Interacción Háptica e Inmersiva:** Manipulación directa de cables, fuentes de alimentación y componentes con los controladores VR.
* 📊 **Instrumentación Virtual:** Uso de multímetros y herramientas de medición con lecturas en tiempo real según las leyes de Ohm y Kirchhoff.
* 🛠️ **Arquitectura Modular:** Componentes electrónicos prefabricados (Prefabs) fáciles de instanciar y configurar dentro del escenario virtual.
* 🌐 **Soporte Multiplataforma:** Optimizado para la API de OpenXR y configurado especialmente para dispositivos **Meta Quest 2**.

## 💻 Tecnologías Utilizadas

| Tecnología | Descripción |
| :--- | :--- |
| **Unity 6** | Motor de desarrollo 3D utilizado para el renderizado y física del entorno. |
| **C#** | Lenguaje de programación principal para la lógica de componentes y simulación eléctrica. |
| **OpenXR / Unity XR Interaction Toolkit** | Estándar de integración para el seguimiento de manos, controles y colisiones en VR. |
| **Blender** | Modela el instrumental, herramientas y componentes electrónicos en 3D. |
